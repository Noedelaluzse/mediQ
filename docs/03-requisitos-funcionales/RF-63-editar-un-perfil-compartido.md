# RF-63 — Dar permiso de edición sobre un perfil compartido

- **Módulo:** Perfiles
- **Fase:** Fase 3

## Requisito

Dar permiso de edición sobre un perfil compartido

El dueño puede subir el acceso de una cuenta invitada de ver a editar; los cambios quedan con su autor (`createdBy` / `updatedBy`). Diseño en docs/16.
