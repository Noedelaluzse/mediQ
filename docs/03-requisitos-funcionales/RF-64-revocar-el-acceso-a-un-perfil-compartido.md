# RF-64 — Revocar el acceso a un perfil compartido

- **Módulo:** Perfiles
- **Fase:** Fase 3

## Requisito

Revocar el acceso a un perfil compartido

El dueño quita el acceso cuando quiera; el efecto en el servidor es inmediato y la app del invitado borra la copia local y los avisos de ese perfil. Diseño en docs/16.
