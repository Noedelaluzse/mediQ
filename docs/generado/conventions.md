# Conventions

- TypeScript strict; no `any`.
- Use `ThemedText` / `ThemedView` and `src/constants/theme.ts`; no hard-coded colours.
- Install packages with `npx expo install <pkg>`.
- Before using any Expo/RN API, check the docs for the installed SDK major (57) — see AGENTS.md top section.
- New feature = new files following the existing structure; mirror an existing component's style.
